01About

I read other people's code for fun. Then I find the small thing that's broken or missing. Then I fix it properly, write the test, and send it upstream. That loop — read, fix, ship, review — is how I learned to build.

I'm a school student who fell into programming through Python and never left. What started as turtle graphics became voice assistants, 3D experiments, automation bots — and a habit of reading maintainer reviews like textbooks.
