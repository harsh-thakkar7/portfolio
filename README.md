# Harsh Thakkar — Portfolio

Personal portfolio website for **Harsh Thakkar**, a student developer and
open-source contributor. Showcases open-source contributions (153 merged PRs
across 13 upstream repositories), selected projects, tech stack, and journey.

Live site: https://harsh-thakkar7.github.io/portfolio/

## Highlights

- Scroll-driven, animated single-page site (GSAP + Lenis)
- Real GitHub contribution heatmap pulled from the GitHub API
- Merged-PR ledger and repository breakdown
- Selected work reel, language/stack overview, and timeline
- Fully responsive, accessible, reduced-motion aware

## Tech

- HTML, CSS, vanilla JavaScript
- GSAP 3 + ScrollTrigger
- Lenis smooth scrolling
- Google Fonts (Space Grotesk, Fraunces, IBM Plex Mono)

## Run locally

Just open `index.html` in a browser — no build step required.

```bash
open index.html
```

## Deploy

The site is a static single file, so it can be served from any static host.
A GitHub Pages workflow is included in `.github/workflows/pages.yml`.
